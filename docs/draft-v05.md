# v0.5 · 데이터 수집 안내와 기획서 초안

## 사용 순서

1. 기획을 선택 목록에 추가합니다.
2. ‘필요 데이터와 수집처’를 펼쳐 업무 담당자·시스템·공식 자료 등 권장 수집처와 수집 방법을 확인합니다.
3. 자료마다 성격(실제 / 가정·추정 / 가상), 실제 출처 또는 원본 파일명·담당자, 기준 기간·대상·단위, 핵심 내용, 한계를 입력합니다.
4. 질문에 내 답을 쓰고 연결할 자료 번호를 입력합니다. 여러 번호는 쉼표로 구분합니다. 공통 내용은 ‘공통 기획의 근거 연결’을 펼쳐 입력합니다.
5. ‘기획서 초안 만들기’를 누르면 개요·공통 기획·분야별 내용·입력 자료·검증 제안·실행 제안·근거 목록·미확인 사항을 구성합니다.
6. 근거와 결론을 검토한 후 Markdown을 내려받습니다. JSON 백업에는 원래 답변·자료·연결 번호가 들어 있어 다시 편집할 수 있습니다.

파일 첨부·PDF나 엑셀 추출·URL 본문 읽기는 이 버전에 없습니다. 실제 자료의 핵심 내용을 직접 입력합니다. 외부 AI나 서버로 자료를 전송하지 않습니다. 자료 자체를 자동 조사하거나 요약·해석한 사실을 만들어 내지 않고 입력한 내용을 지정 구조에 반영합니다.

## 상태의 의미

| 조건 | 초안에 표시 |
|---|---|
| 자료 내용이 없음 또는 미확인으로 입력됨 | 미확인 — 자료 내용 없음 |
| 가상·연습 자료 | 미확인 — 가상·연습 자료 |
| 가정·추정 또는 성격 미지정 | 미확인 — 가정·추정 자료 |
| 실제 자료지만 출처나 기준 기간 부족 | 미확인 — 출처 또는 기준 기간 부족 |
| 실제 자료로 지정하고 내용·출처·기간 입력 | 입력 근거 연결 — 원문·주장 적합성 미검증 |
| 답변에 사용할 수 있는 선택 자료 번호가 연결되지 않음 | 미확인: 연결된 실제 근거 없음 |

실제 자료라는 지정은 사용자의 입력입니다. 출처·내용·기간이 있다는 이유만으로 진실·대표성·계산 정확성·주장과의 관계가 검증됐다고 표시하지 않습니다. 가상 자료는 번호를 연결해도 실제 근거로 승격되지 않습니다. 추천 수집처 역시 수집된 근거로 사용하지 않습니다.

기획 제목·대상·기간은 개요에서 작성자 설정으로 소개하며 관련 상세 항목은 별도로 근거 상태를 표시합니다. 계획·목표의 실현 가능성을 자동 판단하지 않습니다. 지표 값·일정·예산·최종 판정은 미확인 또는 사용자 입력으로 남기고 새 수치를 만들어 넣지 않습니다.

## 자료 보존과 갱신

기획을 해제해도 브라우저 작성본의 자료·답변은 보존합니다. 해제한 기획의 자료는 현재 초안과 근거 목록에서 제외되며 다시 선택하면 복원됩니다. 다른 선택 기획의 실제 자료는 근거 번호로 연결할 수 있지만 내용이 해당 주장을 뒷받침하는지는 직접 검토해야 합니다.

자료를 바꾸면 미리보기는 이전 내용이라는 안내를 표시합니다. 초안 버튼을 다시 누르면 갱신되며 내려받기는 항상 현재 입력 내용으로 다시 생성합니다. 초기화·다른 백업 복원 시 미리보기를 지워 혼동을 줄입니다.

v0.3·v0.4 백업은 기존 내용을 보존해 읽고 자료·근거 연결은 빈 상태로 시작합니다. 저장 공간은 접속 주소·브라우저에 따라 달라지므로 이동 전 JSON을 백업합니다.

## 권장 수집처의 범위

업무 기록은 실제 운영 담당자가 관리하는 원본을 우선합니다. 공식 포털은 필요할 때 자료를 찾는 입구로 제공합니다. 포털에 필요한 세부 자료가 실제로 있는지, 대상과 기간이 맞는지는 추가 확인합니다.

- [KOSIS](https://kosis.kr/): 통계 탐색 입구
- [공공데이터포털](https://www.data.go.kr/): 공개 데이터 탐색 입구
- [한국관광 데이터랩](https://datalab.visitkorea.or.kr/): 숙박·관광 분야 탐색 입구
- [K-Startup](https://www.k-startup.go.kr/web): 해당 지원사업 공고·양식 확인 입구

위 사이트의 접근·주요 서비스 소개는 2026-10-26 확인했습니다. 특정 통계나 공고 내용이 사용자 기획의 근거라고 검증한 것은 아닙니다.

## 검증

`node scripts/check-draft.cjs`는 63개 기획의 수집 안내, 빈 자료·가상·추정·출처/기간 누락·알 수 없는 번호·해제한 자료 제외를 확인합니다. `node scripts/check-planning.cjs`는 기존 선택·호환·저장 구조와 자료·연결 번호의 정규화를 확인합니다.
