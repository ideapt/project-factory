# v0.4 · 세 입구로 찾는 통합 기획

## 범위

직무 16개, 사업장 8개, 목적 8개로 기획을 찾습니다. 63개 기획은 중복 생성하지 않고 고유 번호로 연결합니다. 기존 9개 분야는 양식 정리용으로 유지하며 화면의 첫 선택 기준에서는 분리했습니다.

공식 직업분류와 NCS를 검토해 프로젝트 공장용으로 재구성한 자체 분류입니다. 전체 직업군을 포괄하거나 공식 코드에 일대일 대응한다고 주장하지 않습니다. 이번 범위는 호텔·레지던스·FM과 공통 지원직무의 우선 확장입니다. 제조·의료·농업 등 전문 기획은 후속 영역입니다.

## 찾는 방법

1. 왼쪽에서 직무별·사업장별·목적별 중 하나를 고릅니다.
2. 항목을 펼쳐 기획을 바로 둘러보거나 ‘이 조건으로 찾기’를 누릅니다.
3. 가운데의 세 선택 상자로 조건을 교차 적용합니다. 세 조건을 모두 만족해야 결과에 나옵니다.
4. 검색어는 선택한 조건 안에서 기획명·질문·데이터·분류 명칭을 검색합니다.
5. 결과가 없으면 일부 조건을 전체로 바꾸거나 ‘검색·조건 초기화’를 누릅니다.
6. 기획을 열어 추가하고 아래 작성 영역에서 답변합니다. 탐색 조건을 바꾸어도 선택 목록과 답변은 유지됩니다.

왼쪽 분류도는 해당 기준 전체 목록입니다. 교차 필터 결과는 가운데 카드 목록에 표시합니다. 조건 밖 기획을 열면 상세 화면에 표시하며, 필요하면 수동으로 통합 목록에 추가할 수 있습니다. 필터는 기획에 대한 추천 적합성을 보장하지 않습니다.

## 확인할 수 있는 조합

| 조건 | 결과 예 |
|---|---|
| 인사·교육·근무운영 + 호텔 + 일상·연간 운영 | 조직·인력, 용역·인력 배치, 교대·근무편성, 급여·근태 업무 개선 |
| 미화·객실정비 + 호텔 + 일상·연간 운영 | 미화 운영·품질, 객실정비·린넨 운영 |
| 레지던스·입주지원 + 레지던스 + 일상·연간 운영 | 계약·생활서비스·입퇴주 전환·청구수납·생활지원 |
| 구매·물류·재고 + 호텔 + 구매·계약·인력 확보 | 용역·인력 배치, 구매·조달, 협력업체 선정·평가 |

결과는 여러 분류 태그의 연결에 따라 달라집니다. 적용 사업장과 직무·목적은 상세 화면과 유형별 양식에 표시합니다.

## 추가한 27개 기획

- 공통 지원 11개: 채용·배치, 직무교육·적응, 교대·근무편성, 급여·근태, 결산·회계, 세무 일정·증빙, 구매·조달, 협력업체, 재고, 자산·공간, 계약·갱신
- FM 8개: 현장 인수, 전기설비, 기계·공조, 미화, 보안, 주차, 안전·보건, 비상대응
- 호텔 5개: 예약·프런트, 객실정비·린넨, 식음료·조식, 연회·행사, 불만·서비스 회복
- 레지던스 3개: 입퇴주 전환, 청구·수납·반환, 입주자 지원·생활 운영

각 기획에는 별도의 4개 질문, 데이터, 지표, 검증 관점을 제공합니다. 실제 수치나 규정·세무·안전 판단은 자동으로 채우지 않습니다.

## 호환성과 보관

기존 모듈 번호와 질문 문구를 유지했습니다. v0.3 JSON은 v0.4로 정규화해 공통 내용·선택·답변·확인 기록을 복원합니다. 기존 브라우저 저장 키도 유지합니다. 브라우저 저장은 동일 주소·브라우저에서만 이어지며 파일 주소와 로컬 서버 주소·포트가 다르면 저장 공간도 다를 수 있습니다. 그 경우 JSON 백업으로 옮깁니다.

신규 버전의 기획을 포함한 작성본을 옛 시안으로 다시 여는 역방향 호환은 지원하지 않습니다. 기존 백업을 보존하세요. 필터 조건은 탐색용으로만 사용하며 기획의 적용 조건을 자동 확정하거나 백업에 저장하지 않습니다.

## 유지관리

기존 데이터는 `prototype/catalog.js`, 추가 유형과 분류 태그는 `prototype/catalog-v04.js`입니다. 화면과 Node 양식 생성기가 같은 확장 데이터를 사용합니다. 신규 유형에는 roles·workplaces·purposes 태그를 모두 부여합니다. 양식 재생성: `node scripts/export-templates.cjs`. 검증: `node scripts/check-planning.cjs`.
