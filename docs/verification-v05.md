# v0.5 검증 기록

검증일: 2026-10-26

## 확인 결과

- 63개 기획의 모든 필요 데이터에 권장 수집처·수집 방법이 제공되는지 확인했습니다.
- 자료 내용 없음, 가상·추정, 실제 출처·기간 누락, 잘못된 근거 번호를 미확인으로 분류하는지 확인했습니다.
- 실제로 지정한 자료의 필수 입력이 있어도 원문·주장 적합성 미검증 표시가 유지되는지 확인했습니다.
- 선택 해제한 기획의 자료가 초안에서 제외되는지 확인했습니다.
- 자료·근거 번호의 저장·정규화와 v0.3·v0.4 작성본 호환을 확인했습니다.
- 브라우저에서 객실정비 기획을 선택하고 가상 자료·출처·기간·답변·근거 번호를 입력해 초안을 생성했습니다.
- 생성 본문에 입력 내용과 출처가 포함되고 가상 자료·근거 없는 답변은 미확인으로 남는지 확인했습니다.
- 새로고침 후 입력 자료가 복원되는지 확인했습니다.
- [생성 화면](../prototype/preview-v05.jpg)을 저장했습니다.

자동 검사: `node scripts/check-planning.cjs`, `node scripts/check-draft.cjs` 및 변경한 JavaScript의 `node --check`.

## 연습 자료

[복원용 가상 JSON](../examples/material-draft-demo.json)과 [같은 자료로 생성한 기획서](../examples/material-draft-demo.md)를 제공합니다. 실제 사업 근거로 사용할 수 없습니다.

## 검증 한계

실제 원문·주장 관계나 표본·수치·계약·규정은 자동 검증하지 않습니다. 이번 브라우저 검사는 가상 자료 시나리오이며, 실제 자료의 입력 조건 판정은 자동 검사로 확인했습니다. 파일 선택창을 통한 JSON 복원 전체 절차와 다운로드 대화상자는 이번 버전에서 별도 재실행하지 않았습니다. 수집처 사이트는 안내 링크의 공개 소개를 확인한 것이며 특정 데이터의 가용성을 보장하지 않습니다.
