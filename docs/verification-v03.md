## 검증 한계

JSON 복원 정규화는 자동 검사했으나 실제 브라우저 파일 선택창을 통한 복원 전체 흐름은 별도 확인하지 않았습니다. 모바일 실기기·스크린리더·다중 브라우저·대량 작성 데이터는 검증하지 않았습니다. 반응형 스타일과 입력 라벨·키보드 포커스 표시는 구현했습니다. 자동 데이터 조사·수식 계산·충돌 판정·AI 본문 생성·계정·다중 프로젝트·서버 저장·승인 절차는 구현 범위에 없습니다.
