# 프로젝트 공장 자체 사업 기획 예시

- 구분: 별도 사업 검토 예시.
- 사용 목적: 10개 항목의 형식·근거·미확인 표현 참고.
- 구현 지시: 이 내용을 모든 사용자 기획서의 기본 본문으로 삽입하지 않음.
- 자료 한계: 제품 문서 외 고객 인터뷰·결제·시장 조사 미제공.

## 1 기획 개요

- 기획명: 프로젝트 공장 활용 검증·수익화 검토.
- 목적: 일반 사용자 과업·유료 수요 확인.
- 기능 근거: 기획 탐색·파일 추출·출처 연결·문서 출력. [../../README.md](../../README.md)
- 제안 대상: 혼자 기획서를 작성하는 실무자·예비 창업자.
- 기간·예산·담당·승인자: 미확인.

## 2 현황과 문제

- 확보: 브라우저 기반 기획·OCR·Word/PDF 출력.
- 미확인: 실제 작성 효과·지불 의사·수익성.
- 가정: 분야별 질문·필요 데이터 안내가 작성 시작에 도움.

## 3 데이터 수집·검증 계획

| 데이터 | 목적 | 확보 | 제안 수집처·방법 | 검증 |
|---|---|---|---|---|
| 실제 작성 과업 | 우선 고객 선정 | 미확인 | 실무자 인터뷰·기존 문서 확인 | 실제 업무·빈도 확인 |
| 작성 시간·누락 | 사용 효과 확인 | 미확인 | 같은 과업 관찰·실무자 검토 | 범위·자료 조건 통일 |
| 구매 의사·결제 | 유료 수요 확인 | 미확인 | 제공 범위·가격 제시 후 시범 운영 | 호감·의사·실결제 구분 |

## 4 대안 비교

- 현행 유지: 무료 버전 운영·사용 문제 관찰.
- 제안: 분야별 양식·작성 지원의 유료 수요 검증.
- 조직용 확장: 조직 요구·예산 확인 후 검토.
- 비용·기간·우열: 미확인.

## 6 예산과 기대 효과

- 비용: 개발·서버·고객 모집·작성 지원 — 미확인.
- 검토식: 실제 수행 건수 × 평균 실결제액.
- 계산 결과: 미확인 — 입력값 미확보.
- 제안 지표: 과업 완료·시간·재작성·검토 누락.
- 기준선·목표·측정 기간: 미확인.
