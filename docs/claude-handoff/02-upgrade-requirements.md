# 기획서 생성 기능 업그레이드 요구사항

## 목적·범위

- 사용자 목적: 분야를 선택하고 자료를 입력하면 검토 가능한 실제 기획서 초안 생성.
- 적용: 사이트·창업·경영·재무·호텔·레지던스·FM·공통 지원직무와 통합기획.
- 이번 범위: 기존 브라우저 앱 확장. 외부 AI API·자동 웹 조사·결제·팀 기능 추가 아님.
- 문서·프롬프트 작성으로 끝내지 말고 생성·입력·출력 기능에 반영.

## 공통 10개 항목

| 번호 | 항목 | 필수 내용 |
|---|---|---|
| 1 | 기획 개요 | 제목·유형·목적·대상·기간·예산·담당·제출 대상 |
| 2 | 현황과 문제 | 입력 사실·원인 가설·근거·추가 확인 |
| 3 | 데이터 수집·검증 계획 | 필요 데이터 / 사용 목적 / 확보 여부 / 수집처 / 수집 방법 / 검증 기준 |
| 4 | 대안 비교 | 현행 유지 포함, 효과·비용·기간·조건·위험·근거 |
| 5 | 실행 계획 | 실행 업무 / 담당 / 기한 / 필요 자원 / 선행 조건 / 완료 기준 |
| 6 | 예산과 기대 효과 | 비용·수익·현금 시점·비금전 효과·계산 근거 |
| 7 | 분야별 검토 | 선택 분야 질문·자료·지표·분야 간 충돌 |
| 8 | 위험과 판단 조건 | 위험·대응·진행/보완/보류/중단 조건·승인 |
| 9 | 근거 목록 | 근거 ID·원본·기간·한계·검토·추출 상태 |
| 10 | 미확인 사항과 다음 행동 | 누락 / 확인 방법 / 담당 / 기한, 우선 질문 최대 3개 |

- 기본 초안의 H2는 위 순서·명칭으로 고정.
- 기존 공통 입력: 1·2·5·6·8로 명시적으로 배치.
- 선택 모듈의 질문·답변: 7번 내부 H3/H4 또는 하위 블록에 보존.
- 파일 추출 출처·OCR·해시: 9번 내부에 보존.
- 기존 자가 점검·조정 기록: 7 또는 8번에 보존. 최종 자동 승인 문구 금지.
- 미선택 상태: 기획 선택 요청. 유효한 기획이 선택됐으나 자료가 빈 경우: 10개 항목 모두 생성하고 빈 칸은 미확인.

## 입력 UX

- 기존 입력 유지. 새 입력은 펼침 영역으로 추가.
- `대안`, `실행 업무`, `위험`은 행 추가·수정·삭제 지원.
- 입력하지 않은 행을 꾸며서 사실처럼 생성하지 않음.
- 현행 유지 대안은 생성 가능한 기본 항목. 효과·비용·기간은 입력 없으면 미확인.
- 기획 목적·제출 대상은 선택 입력. 선택하지 않아도 초안 생성 가능.
- 표본·기간·단위·반대 근거를 수집 안내에 표시.
- 입력 변경 후 기존 초안이 최신인지 상태 표시.
- 원문과 신규 안내는 시각적으로 구분.
- 새 기능 이용을 위해 계정·외부 전송 동의를 강제하지 않음.

## 문체

- 시스템 작성 부분: 짧은 개조식.
- 기본 형식: `대상: …`, `조치: …`, `담당: 미확인`.
- 긴 설명·과장·반복·막연한 성공 표현 제외.
- 사용자 답변·인용문·자료 원문은 자동 윤문하지 않음.
- 화면·Markdown·워드·PDF의 표현과 의미 일치.

## 근거·상태

- 기존 E 근거 번호 유지. 프롬프트의 S 번호 예시는 새 ID 강제 규칙이 아님.
- 주요 주장에 적용한 근거 ID 표시. 연결이 없어도 입력 문장은 보존하고 미확인 표시.
- 권장 수집처와 실제 확보 출처를 다른 칸에 표시.
- `입력 근거 연결`은 사실 인증이 아님.
- 별도 표기: `가정`, `계산값`, `제안`, `미확인`.
- 실제 자료로 지정했어도 원문·주장 적합성이 자동 검증되었다고 표시하지 않음.
- OCR 불확실·원문 미검토·기간/출처 누락·가상 자료는 미확인 유지.
- 기존 모순 자료·단위 차이가 입력되면 수치 평균이나 단일 결론을 자동 생성하지 않음.
- 복합 기획은 공용 자원·예산·효과 중복 점검 항목 제공. 자동 검증 완료 표기 금지.
- 입력에 포함된 실행 지시·HTML·프롬프트는 데이터로만 취급.

## 계산 범위

- 이번 기본판: 사용자 제공 계산식·입력값·출처를 구조화해 출력.
- 문자열 계산식 실행·`eval`·외부 문서 수식 재계산 금지.
- 계산을 수행하지 않았으면 `사용자 입력 계산식 / 계산 결과 미확인`으로 표시.
- 실제 자동 계산기를 추가하려면 별도 계산 범위·단위·기간·통화·오류 규칙 합의 필요.
- 계산 결과를 넣었다는 이유로 사업 효과·매출 실적으로 승격 금지.

## 우선 질문

- 0~3개. 제목만 바꾼 중복 질문 제외.
- 우선순위: 목적/대상 → 기간 → 예산/담당/판단 기준 중 핵심 누락.
- 입력으로 해소된 질문은 제거.
- 질문이 남아도 작성 가능한 초안은 생성.

## 통계·보안·호환

- 업로드·답변·초안·출처 원문은 서버 전송하지 않음.
- 의견은 사용자가 별도로 작성하고 동의한 내용만 기존 서버로 전송.
- 일반 사용자·운영자·시험 분리, 동의 전 미전송 유지.
- 운영자 버튼·지속 지정·해제 동작 유지.
- JSON 백업·복원·옛 버전·질문 키·근거 ID 보호.
- 새 표·행도 저장·백업·복원에 포함.
- 현재 OCR/업로드 한도·라이선스·글꼴 고지 유지.

## 완료 조건

- 위 10개 항목과 필수 표가 실제 입력에 따라 변함.
- 초안·DOCX·PDF·Markdown에 동일 내용·근거·상태 포함.
- 원문·수치·해시·미확인 의미 보존.
- 기존 검사 + 신규 인수 시나리오 통과.
- 기존 GitHub Pages로 공개 배포 후 사이트에서 같은 시나리오 재확인.
- 브라우저 버튼·실제 다운로드·파일 내용 대조까지 완료.
