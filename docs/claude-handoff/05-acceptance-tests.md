# 인수 검증 기준

- 모든 예시: 가상 시험 자료.
- 일반 사용자 통계에 시험 작업을 넣지 않음.
- 브라우저·파일 검사는 코드 검사와 별도로 수행.

## 보호 자료 시험 값

- 금액: `-1,234.50원`, `0.00%`.
- 날짜: `2026-10-27`.
- 직접 인용: `"추가 인력이 필요하다는 결론은 아니다."`.
- 원문 위치: `자료 A.xlsx / 시트 "객실·운영"!B2`.
- URL: `https://example.test/source?a=1&b=2`.
- 기호: `A|B`, `# 원문 제목`, `<script>시험</script>`.
- 상태: `미확인 — 인식 불확실`.
- 해시·OCR 점수: 기존 check-draft-style fixture 참조.

## 브라우저 순서

1. 기존 작성본 JSON 백업.
2. 시험 주소 또는 로컬 미리보기에서 진행.
3. 기획 선택·원본 자료 입력·대안/실행/위험 행 작성.
4. 새로고침 후 행·근거·입력 유지 확인.
5. 초안 생성, 10개 항목·필수 표·미확인 확인.
6. Markdown·DOCX·PDF 실제 버튼으로 다운로드.
7. 파일 열기·목차 이동·표·출처·수치 대조.
8. 비어 있는 입력·원문 미검토·복합 기획으로 반복.
9. 백업 복원 후 동일 내용 확인.
10. 시험·운영자 기록의 일반 사용자 집계 제외 확인.

## 증거

- 검사 명령·실행 시각·종료 코드·요약.
- 사용한 가상 입력·생성 파일 경로.
- 초안·표·운영 구분 화면 캡처.
- 완료·미완료·환경 제한을 분리한 결과 표.
- 단순 화면 표시나 다운로드 버튼 클릭만으로 파일 내용 검증 완료 처리 금지.
