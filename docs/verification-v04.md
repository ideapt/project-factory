## 브라우저 확인

- 호텔 + 인사·교육·근무운영 + 일상·연간 운영 → 조직·인력, 용역·인력 배치, 교대·근무편성, 급여·근태 업무 개선 표시
- 직무를 미화·객실정비로 변경 → 미화 운영·품질, 객실정비·린넨 운영 2개 표시
- 교대·근무편성 선택 후 조건 변경·새로고침 시 선택 목록 보존
- 직무별·사업장별·목적별 입구 전환 후 교차 조건 유지
- 좁은 브라우저 화면에서 조건·결과 카드의 세로 배치 확인
- [교차 검색 화면](../prototype/preview-v04.jpg) 저장

## 한계

브라우저의 파일 선택창을 통한 v0.3 백업 복원 전체 절차는 이번에 별도로 실행하지 않았고 복원 정규화 로직을 검사했습니다. 새 버전의 파일 다운로드 대화상자도 재실행하지 않았으며 기존 내보내기 동작은 코드 검사로 확인했습니다. v0.3에서는 실제 다운로드 파일을 확인했습니다.

실제 직무 전문가에 의한 양식 검토, 현장 사업성·규정·계약 판단, 모든 기기·브라우저·스크린리더 검증은 완료하지 않았습니다. 이 버전은 로컬 기획 작성 시안입니다.
