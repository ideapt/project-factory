# v0.6 검증 기록

검증일: 2026-10-26

## 실제 브라우저 확인

- 가상 DOCX: 한글 본문·표를 읽고 본문 문단과 표·행·셀 위치 표시
- 가상 XLSX: 한글 시트명과 B2 값 20, 첫 행·첫 열 문맥 표시
- 엑셀 B4 수식: 저장 계산값 없음·재계산 안 함을 미확인으로 표시
- 가상 PDF: 1페이지 텍스트 읽기, 2페이지 텍스트 없음을 OCR 미지원·미확인으로 표시
- 세 파일의 발췌를 같은 데이터 항목에 반영하고 파일명·위치·SHA-256이 초안에 포함되는지 확인
- 검토 전 추출 자료가 미확인 상태인지 확인
- 새로고침 후 추출본·파일 식별·반영 발췌의 위치가 유지되는지 확인

최초 PDF 시험은 최신 라이브러리의 문서 객체에 없는 정리 메서드를 호출해 실패했습니다. 로딩 작업의 정리 메서드를 사용하도록 수정했고 같은 PDF 재업로드로 통과를 확인했습니다. 자동 회귀 검사에도 같은 API 조건을 추가했습니다.

## 자동 확인

`node scripts/check-files.cjs`는 실제 XLSX 읽기, 셀 주소·수식·해시, 검토 상태, 불확실 추출의 미확인 유지, 중복 발췌 방지, 크기·형식 제한, PDF 정리 API와 빈 페이지 처리를 검사합니다.

`node scripts/check-planning.cjs`, `node scripts/check-draft.cjs`로 기존 선택·백업 정규화·초안 상태 검사도 수행했습니다. 변경 JavaScript 문법과 내부 문서 링크도 확인했습니다.

## 한계

실제 고객 원문·복잡한 PDF 표·서로 다른 언어/글꼴·암호화 파일·모든 기기와 브라우저·최대 한도 파일을 전부 시험하지 않았습니다. 실제 브라우저 시험은 로컬 HTTP 주소에서 수행했습니다. 일반 파일 주소용 스크립트를 포함했지만 파일 주소에서의 업로드 전체 흐름은 별도 확인하지 않았습니다.

OCR·DOC/XLS 변환·Excel 수식 재계산·Word 페이지 재배치·자동 사실 검증·변조 방지 감사 기능은 없습니다. 파일 추출은 내용을 찾는 보조이며 기록된 한계와 원문을 확인해야 합니다.
