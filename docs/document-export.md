# 워드·PDF 내려받기

작성 화면을 새로고침한 뒤 ‘내 기획 만들기’에서 기획을 선택하고 자료를 입력합니다. 하단의 ‘워드 내려받기 (.docx)’ 또는 ‘PDF 내려받기 (.pdf)’를 누릅니다. 현재 입력으로 초안을 다시 만들어 미리보기와 파일에 같은 내용을 담습니다. 기획 선택이 없으면 안내만 표시합니다.

- 두 형식 모두 제목·목차·본문·출처 표·근거 목록·파일 출처와 추출 상태·미확인 사항·페이지 번호를 포함합니다.
- PDF 목차는 페이지 번호와 이동 링크를 제공합니다. 워드 목차는 본문으로 이동하는 링크이며, 페이지 번호는 바닥글에 표시됩니다. Word의 제목 스타일을 사용하므로 필요하면 Word에서 자동 목차를 추가할 수 있습니다.
- 연속된 ‘항목: 내용’ 자료는 두 열의 표로 표시합니다. 나머지 문장은 그대로 실으며 금액·백분율·소수·음수·근거 번호·해시·원문 위치·인식 점수를 다시 계산하거나 교정하지 않습니다. 미확인 표시는 삭제하거나 확인 완료로 바꾸지 않습니다.
- PDF에는 배포 가능한 나눔고딕을 포함합니다. Word는 컴퓨터에 있는 글꼴을 사용하므로 설치 환경에 따라 줄바꿈과 페이지 수가 달라질 수 있습니다. 원본 OCR 페이지 이미지는 내보내지 않으며 파일명·위치·해시·추출 원문을 제공합니다. 원본 이미지 대조는 작성 화면에서 합니다.
- 파일 생성은 브라우저 안에서 처리합니다. 인터넷 연결과 별도 서버가 필요하지 않으며, 자료를 외부 서비스로 보내지 않습니다. 원본 PDF의 편집 레이아웃을 복원하는 기능은 아닙니다.

## 검증

`npm run check`는 합성 예시로 DOCX의 전체 문장·표·목차 링크와 PDF의 한글·전체 문장·수치·미확인·URL 보존을 검사하고 실제 파일을 만듭니다. 긴 내용이 여러 페이지로 이어지는 경우도 검사합니다. PDF를 이미지로 렌더링해 확인했습니다. Word 앱의 실제 화면과 프로그램별 출력 모양은 이 자동 검사에 포함하지 않습니다.

예시 파일 `examples/export/synthetic-plan.docx`, `examples/export/synthetic-plan.pdf`는 실제 사업 자료가 아닌 합성 시험용입니다.

실제 브라우저의 두 버튼으로 다운로드한 파일도 별도로 점검했습니다. [실제 다운로드 점검 결과](verification-document-export.md)에 파일·화면 기록과 검사 범위를 남겼습니다.
