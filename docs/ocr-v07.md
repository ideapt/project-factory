# v0.7 · 스캔 PDF OCR과 원본 대조

## 실행

프로젝트 폴더의 `로컬 실행.cmd`를 더블클릭합니다. Python이 설치된 이 컴퓨터에서 루프백 주소 `http://127.0.0.1:8870/prototype/`를 엽니다. 실행 창을 닫거나 Ctrl+C를 누르면 종료합니다. 다른 컴퓨터에서 접속하도록 열지 않습니다.

파일 주소(file://)는 브라우저 작업자·언어 파일 읽기가 제한되어 OCR을 실행하지 않습니다. 화면에 로컬 실행 안내를 표시하고 읽지 못한 부분은 미확인으로 남깁니다. 이전 파일 주소의 작성본은 먼저 JSON으로 백업한 뒤 새 미리보기에서 불러옵니다. 저장 공간이 주소별로 다르기 때문입니다.

## 읽기와 대조 순서

1. 기획을 선택한 뒤 OCR 문서 언어를 한국어 또는 영어로 고릅니다. 한 문서에 두 언어가 섞이면 주 언어로 읽고 필요하면 다른 언어로 다시 올려 대조합니다.
2. 자동 모드에서는 텍스트 없는 페이지만 OCR로 읽습니다. 텍스트 층이 있어도 잘못 읽히는 문서는 강제 모드로 첫 10페이지를 OCR 비교합니다. 끄기 모드는 기존 텍스트만 읽습니다.
3. 스캔 페이지는 PDF를 이미지로 렌더링한 후 문자 인식을 수행합니다. 페이지별 최대 긴 변 2,200픽셀, OCR은 파일당 최대 10페이지입니다. 제한·실패·인식된 문자 없음은 미확인으로 기록합니다.
4. ‘원본·OCR 대조’를 누르면 원본 페이지 렌더링과 인식된 문장·단어를 함께 봅니다. 개별 문장의 대조 버튼은 그 문장 위치도 이미지 위에 표시합니다. 위치를 못 구하면 원본과 문장만 표시합니다.
5. 필요한 발췌를 데이터에 반영하고 원문·기간·자료 성격을 검토합니다. 인식 점수가 낮은 발췌는 검토 확인란만으로 확정되지 않으며 계속 미확인으로 남습니다. 수정이 필요하면 자료 내용에 올바른 전사와 수정 이유를 적고 원본 추출 기록은 보존합니다.

같은 원본을 다시 올리면 보관한 추출본·페이지 이미지를 갱신합니다. 이미 채택한 발췌는 당시 원문·위치·점수를 가진 기록으로 남습니다. 한국어·영어 인식 결과의 발췌 번호는 구분됩니다.

## 미확인 기준

- 문장 점수 85 미만, 단어 점수 75 미만, 점수나 단어별 정보가 없으면 해당 문장은 미확인입니다.
- 낮은 점수의 단어는 원본 대조 창에서 강조합니다.
- 점수는 OCR 엔진의 내부 지표이며 정확도 확률이나 사실 확인 결과가 아닙니다. 높은 점수에서도 숫자·이름·단위·영문·띄어쓰기 등이 틀릴 수 있습니다.
- 임계값은 이 시안의 보수적인 검토 보조 기준이며 한국어·영어 모든 문서에 검증된 정확도 기준이 아닙니다.
- 고득점 문장도 원문 검토 전에는 미확인입니다. 원문 검토 후에도 사실·주장 적합성은 자동 검증하지 않습니다.
- 회전·기울임·희미한 글씨·필기·도장·표 구조·다단 배치는 제대로 인식하지 못할 수 있습니다. 표의 셀 구조나 계산 결과를 자동 추정하지 않습니다.

## 저장·개인정보·성능

PDF와 페이지 이미지를 외부 OCR 서비스로 보내지 않습니다. OCR 엔진·언어 데이터는 `prototype/vendor/ocr`의 로컬 파일을 읽습니다. 원본 PDF 바이너리 대신 비교용 JPEG 렌더링·해시·문장·점수·좌표를 저장합니다. 원본 자체는 별도로 보관합니다.

페이지 이미지 때문에 브라우저 저장이나 JSON 용량이 커질 수 있습니다. 저장 실패 안내가 나오면 JSON을 내려받고 문서를 나누어 작업합니다. JSON 복원 최대 30MB·보관 이미지 최대 10개이며 같은 주소에서만 자동 저장이 이어집니다. 일부 백업에 이미지가 없으면 원본 이미지를 확인할 수 없다는 미확인 안내가 나옵니다.

[가상 스캔 PDF](../examples/upload-fixtures/synthetic-scan.pdf)와 [그 이미지](../examples/upload-fixtures/synthetic-scan.png)를 제공합니다. 실제 현장 근거가 아닙니다. 개발용 `prototype/ocr-smoke.html`은 이 가상 파일만 읽어 검사하고, 현재 주소에 기존 기획이 없을 때만 가상 연습 기획을 만듭니다.

`node scripts/check-ocr.cjs`로 실제 한글 이미지 인식과 점수·좌표·미확인 규칙을 검사합니다. [검증 기록](verification-v07.md)을 참고하세요.
