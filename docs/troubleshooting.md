# 자주 생기는 문제

| 증상 | 확인할 것 |
|---|---|
| 실행 창이 바로 닫힘 | ZIP을 완전히 풀었는지, Python 3이 설치됐는지 확인합니다. 터미널에서 `python scripts/serve-preview.py`를 실행하면 오류를 읽을 수 있습니다. |
| 8870 포트를 사용할 수 없음 | 이전에 실행한 미리보기 창을 찾아 Ctrl+C로 종료하고 다시 실행합니다. 다른 프로그램의 포트 사용이 원인이면 아래 수동 방법을 사용합니다. |
| 브라우저가 자동으로 안 열림 | 실행 창을 열어 둔 채 `http://127.0.0.1:8870/prototype/`를 직접 엽니다. |
| OCR을 실행할 수 없음 | 파일 주소 대신 로컬 실행.cmd로 연 주소인지 확인합니다. 문서 언어를 한국어 또는 영어로 선택합니다. |
| 스캔 PDF 일부만 처리됨 | OCR은 파일당 최대 10페이지입니다. 처리되지 않은 부분은 미확인으로 남습니다. |
| DOC·XLS를 읽지 못함 | 원래 프로그램에서 DOCX·XLSX로 저장한 뒤 사용합니다. |
| 파일을 읽었는데 초안에 없음 | 반영할 데이터 항목을 선택하고 블록을 반영한 뒤 질문의 근거 번호를 연결합니다. |
| 자료를 넣어도 미확인 | 실제/가상/가정 여부, 출처, 기간, 원문 검토와 추출 불확실성을 확인합니다. 가상·추정·낮은 OCR 점수는 체크만으로 확인 상태가 되지 않습니다. |
| 기획을 봤는데 다운로드 내용에 없음 | ‘내 기획에 추가’를 눌러 선택 목록에 넣었는지 확인합니다. |
| 워드·PDF 파일이 안 보임 | 다운로드 목록과 다운로드 폴더를 확인합니다. 화면의 실패 안내가 있으면 그 내용을 기록합니다. |
| Word가 제한된 보기로 열림 | 인터넷에서 받은 문서의 일반적인 표시입니다. 읽기·검토는 제한된 보기에서 할 수 있습니다. |
| Word와 PDF 페이지 수가 다름 | 프로그램별 글꼴과 문단 배치가 다릅니다. 수치·출처·내용을 비교합니다. Word 목차는 이동 링크이며 PDF처럼 목차에 쪽번호를 넣지는 않습니다. |
| 저장 내용이 사라짐 | 다른 브라우저·주소인지 확인하고 JSON 백업을 불러옵니다. 브라우저 기록 삭제 후에는 JSON이 필요합니다. |
| 자동 저장 실패 | 큰 OCR 이미지가 저장 공간을 넘을 수 있습니다. JSON을 내려받아 보관합니다. |

다른 포트로 실행하려면 프로젝트 폴더에서 아래 명령을 사용하고 브라우저 주소에 `/prototype/`까지 넣습니다.

```sh
python -m http.server 8871 --bind 127.0.0.1
```

주소: `http://127.0.0.1:8871/prototype/`. 포트가 바뀌면 기존 저장본과 분리되므로 JSON으로 옮깁니다.

오류 제보에는 운영체제·브라우저·실행 주소의 방식(파일/로컬), 재현 순서와 오류 문구를 적습니다. 실제 고객 자료 대신 가상 재현 자료를 사용하세요.
