# v0.7 OCR 검증 기록

2026-10-26, 가상 시험 자료 기준입니다.

## 확인 결과

- 한국어 이미지에서 ‘객실’, ‘20’ 인식과 문장·단어 점수·좌표 출력을 실제 OCR 엔진으로 확인
- 영어 단일 언어 OCR에서 가상 이미지의 ‘SYNTHETIC’ 인식 확인
- 실제 브라우저에서 이미지로만 된 PDF를 렌더링·OCR하여 1페이지·5문장 추출
- ‘객실 수: 20개’, ‘정비 시간: 30분’ 인식 확인
- 틀리게 읽힌 영문과 낮은 점수 단어의 미확인 표시 확인
- 원본 이미지와 OCR 결과 대조 창, 문장·단어 점수 표시 확인
- 추출·이미지·좌표·점수의 작성본 정규화와 이전 버전 복원 검사
- 낮은 OCR 점수의 발췌가 검토 확인만으로 사용 가능 상태가 되지 않는지 검사

[실제 대조 화면](../prototype/preview-v07.jpg)은 원본과 인식 오류가 함께 보이는 화면입니다. 인식 오류를 수정하거나 감추지 않고 그대로 비교했습니다.

혼합 언어 동시 초기화 시험에서는 언어 로딩 경고를 확인해 문서 언어를 명시적으로 선택하는 방식으로 구성했습니다. 한국어·영어를 각각 별도 실행해 확인했습니다.

## 한계

이 검사는 표본 문서의 기능 검사이며 일반 OCR 정확도 평가가 아닙니다. 필기·기울어진 문서·대용량·복잡한 표·암호화 PDF·모든 브라우저를 검증하지 않았습니다. 파일 주소에서 OCR을 실행하는 기능은 제공하지 않으며 로컬 HTTP 실행이 필요합니다. 로컬 실행 스크립트의 서버 구성은 코드와 동일 방식의 로컬 미리보기로 확인했으며 사용자 더블클릭부터 브라우저 열기 전체 절차는 별도 실행하지 않았습니다.
