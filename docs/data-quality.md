# 데이터 품질을 판단하는 예시

아래는 판단 방법을 설명하는 가상 상황입니다. 실제 조사 결과가 아닙니다.

| 자료와 주장 | 분류 예시 | 이유와 처리 |
|---|---|---|
| 공식 판매 페이지에서 오늘 확인한 요금으로 ‘오늘 공개된 요금’을 기록 | 사용 가능 | 할인·세금·약정 조건을 함께 기록합니다. |
| 같은 요금으로 ‘고객이 실제 지불한 평균 금액’을 주장 | 참고 전용 | 공개 정가와 실제 거래 가격은 다릅니다. |
| 목표 고객 인터뷰 5건으로 ‘이 참여자들이 겪은 문제’를 설명 | 조건부 사용 | 모집 편향과 표본 범위를 밝힙니다. |
| 그 5건으로 ‘전국 고객의 80%가 구매’를 주장 | 사용 제외 | 조사에서 측정하지 않은 모집단 구매율입니다. |
| 오래된 산업 통계를 현재 가격으로 사용 | 참고 전용 | 역사적 맥락으로만 쓰고 현재값을 추가 수집합니다. |
| 같은 보도자료를 인용한 기사 10건 | 하나의 원출처로 관리 | 독립된 10개 근거로 세지 않습니다. |
| 커뮤니티의 불만 게시물 | 참고 전용 | 문제 가설을 만들 수 있으나 발생률은 알 수 없습니다. |
| 결제 8건 중 3건이 환불됨 | 범위 내 사용 가능 | 총결제·환불·순구매를 모두 기록합니다. |
| AI가 출처 없이 제시한 시장 규모 | 사용 제외 | 원자료를 찾기 전에는 추정 입력값으로도 신뢰하지 않습니다. |

## 정리·계산 확인

1. 원자료를 덮어쓰지 않고 가공본을 분리합니다.
2. 중복 고객·중복 주문·같은 기사의 재배포를 구분합니다.
3. 누락값의 이유를 확인하고, 제거·보완 방법과 건수를 남깁니다.
4. 퍼센트의 분자·분모와 시간 범위를 확인합니다.
5. 원·만원, 월·연, 세전·세후, 부가세 포함·제외를 맞춥니다.
6. 상충 자료는 유리한 것만 고르지 말고 정의·기간·표본 차이를 확인합니다.

## 중요한 결론에 필요한 근거

독립적인 자료와 실제 고객 행동을 교차 확인하는 것이 권장됩니다. 다만 출처 개수만 채우지 않습니다. 한 번의 실제 결제는 그 거래를 입증하지만 반복 수요를 입증하지는 않습니다. 검증하지 못한 범위를 결론에 명시합니다.
