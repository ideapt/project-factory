# 설치부터 기획서 다운로드까지

처음에는 가상 호텔 예시로 연습한 뒤 내 자료로 바꿔 보세요. 판단할 근거가 없으면 그대로 미확인으로 둡니다.

## 1. 파일 받기

GitHub에서 **Code → Download ZIP**을 누르고 압축을 완전히 풉니다. README, `로컬 실행.cmd`, `prototype`, `examples`가 함께 보여야 합니다. 일반 사용자는 Node.js나 npm을 설치하지 않아도 됩니다. OCR 데이터와 PDF 글꼴도 포함되어 있습니다.

## 2. 실행하기

Windows에서는 Python 3이 설치된 상태에서 **로컬 실행.cmd**를 두 번 누릅니다. 열린 브라우저 주소가 `http://127.0.0.1:8870/prototype/`로 시작합니다. 실행 중에는 검은 창을 열어 두고, 종료할 때 그 창에서 Ctrl+C를 누릅니다.

Python이 없다면 [Python 공식 사이트](https://www.python.org/downloads/)에서 설치합니다. 이 프로젝트는 Python 3.12에서 확인했습니다. 설치 화면에 PATH 추가 항목이 있다면 선택하고 설치 후 다시 실행하세요.

macOS·Linux는 프로젝트 폴더에서 다음을 실행합니다. 해당 운영체제의 실제 화면 동작은 별도로 검증하지 않았습니다.

```sh
python3 scripts/serve-preview.py
```

브라우저가 자동으로 열리지 않으면 위 주소를 직접 엽니다. Python 없이 간단히 사용하려면 `prototype/index.html`을 직접 여세요. 작성·문서 다운로드는 가능하지만 스캔 PDF OCR은 로컬 서버가 필요합니다. 직접 파일을 여는 방식은 브라우저별 저장 정책이 다를 수 있습니다.

## 3. 가상 예시 불러오기

1. 화면 하단 **백업 불러오기**를 누릅니다.
2. `examples/material-draft-demo.json`을 선택합니다.
3. 현재 작성 내용을 교체한다는 확인창을 읽습니다. 기존 내용은 먼저 **작성본 백업 (.json)**으로 보관합니다.
4. ‘객실정비·린넨 운영’과 ‘객실정비 운영 개선 — 가상 학습 예시’가 입력됐는지 확인합니다.
5. **기획서 초안 만들기**를 누릅니다. ‘가상값: 퇴실 객실 20개’와 ‘미확인’ 표시를 확인합니다.

가상 자료는 출처를 연결해도 확인된 사실이 되지 않습니다. [예시 안내](../examples/README.md)에 입력값과 연습 순서가 있습니다.

## 4. 내 기획 고르기

예시 연습 후 초기화하거나 새 답으로 바꿉니다. 왼쪽의 직무·사업장·목적과 검색창으로 기획을 찾습니다. **질문과 데이터 보기 → 내 기획에 추가**를 눌러야 작성·내보내기에 포함됩니다. 한 가지 업무는 기획 하나, 통합 검토는 여러 기획이나 추천 조합을 선택합니다. 필터를 바꿔도 선택 목록은 유지됩니다.

## 5. 답변과 근거 작성하기

제목·대상·기간·예산·담당자·목표와 배경·실행·비용·위험을 적습니다. 모르면 ‘미확인 — 누가 언제 어떻게 확인할지’로 남깁니다.

‘필요 데이터와 수집처’의 항목을 펼쳐 자료 성격, 실제 출처·원본 위치, 기준 기간·대상·단위, 내용, 한계를 입력합니다. `E-hotel-housekeeping-1` 같은 근거 번호를 해당 질문의 ‘연결할 근거 번호’에 넣습니다. 공통 항목은 ‘공통 기획의 근거 연결’을 펼쳐 연결합니다.

권장 수집처는 조사할 곳의 안내이며 실제 수집한 근거가 아닙니다. 실제 원자료를 확보하지 않았다면 미확인으로 둡니다.

## 6. 자료 파일 사용하기

1. ‘자료 파일 선택’에서 PDF·XLSX·XLSM·DOCX를 고릅니다.
2. 페이지·시트/셀·문단과 추출 내용을 확인합니다.
3. ‘반영할 데이터 항목’을 고르고 **선택 데이터에 반영**을 누릅니다.
4. 기간과 자료 성격을 지정하고 원본을 확인했다면 검토 표시를 남깁니다.
5. 스캔 PDF는 문서 언어를 고른 뒤 **원본 페이지와 대조**에서 숫자·단위·이름을 확인합니다.

낮은 OCR 점수·점수 없음·수식·추출 누락은 검토 체크만으로 확인된 자료가 되지 않습니다. 한도·제약은 [파일 안내](files-v06.md)와 [OCR 안내](ocr-v07.md)를 확인하세요. [가상 시험 파일](../examples/upload-fixtures/README.md)로 먼저 연습할 수 있습니다.

## 7. 검토하고 다운로드하기

초안을 만들고 근거 목록·미확인 사항을 읽습니다. 잘못 입력한 값은 원자료와 대조해 고친 뒤 다시 만듭니다.

| 버튼 | 용도 |
|---|---|
| 워드 내려받기 | 편집 가능한 DOCX. 목차 이동 링크·표·출처 목록·바닥글 페이지 번호 |
| PDF 내려받기 | 한글 글꼴 포함 PDF. 목차 페이지 번호·이동 링크·표·출처 목록 |
| 기획서 내려받기 (.md) | 텍스트로 다른 편집기에 옮길 기획서 |
| 작성본 백업 (.json) | 나중에 이어 쓸 입력값·근거·추출 자료 |

워드·PDF는 현재 입력으로 초안을 다시 만들어 화면과 같은 내용을 내보냅니다. 브라우저 다운로드 목록이나 다운로드 폴더에서 파일을 엽니다. 수치·출처·미확인을 유지하며 원본 OCR 페이지 이미지는 문서에 넣지 않습니다. Word와 PDF의 페이지 수는 다를 수 있습니다.

## 8. 이어서 작성하기

같은 브라우저의 같은 주소로 접속합니다. 저장본이 없으면 JSON을 불러옵니다. 다른 컴퓨터·주소로 옮길 때도 JSON을 사용합니다. 워드·PDF를 올린다고 편집 상태 전체가 복원되지는 않습니다. [문제 해결](troubleshooting.md)도 참고하세요.
