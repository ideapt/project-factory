# 자동 생성 기획서의 문장 기준

- 갱신일: 2026-10-29
- 현재 적용: 개조식 안내·개요·실행 제안
- 구분: 현재 문체 개선은 구현됨 / 공통 10개 항목 업그레이드는 개발 전달 단계

## 적용 범위

- 시스템이 작성하는 설명·개요·실행 제안: 짧은 항목·목록 사용.
- 사용자 답변·인용·자료 원문: 임의 윤문·요약·치환 없음.
- 생성 방식: 브라우저 규칙 기반, 외부 AI 호출 없음.
- 자연스러운 표현 원칙을 참고하되 사용자가 요청한 개조식 기준 우선.

## 문장 규칙

- 기본 형식: `대상: …`, `작성 기준: …`, `담당: 미확인`.
- 한 항목에 하나의 핵심 내용.
- 긴 설명·과장·추상적 수식·반복 제외.
- 직접 입력한 문장·숫자·날짜·단위·부정 표현·출처 보존.
- 자료·가정·제안·미확인을 사실 인증과 구분.
- 원문·해시·파일 위치·OCR 점수·미확인 상태는 문체보다 우선.

## 현재 생성 예

- 작성 기준: 입력 내용·수집 자료
- 별도 검토: 원문·계산·법적 판단
- 권장 수집처: 조사 안내용, 수집된 근거 아님
- 적용 대상: 사용자 입력 또는 미확인
- 사전 확정: 판단 기준·담당자·기한·비용

## 검증

- [수정 전 예시](../examples/draft-style-before.md): 이전 생성 문체 기록.
- [수정 후 예시](../examples/draft-style-after.md): 현재 개조식 생성 결과.
- `node scripts/check-draft-style.cjs`: 수치·미확인 상태·직접 입력·인용·해시·위치·OCR 점수 보존 검사.
- `node scripts/check-export.cjs`: 문서 전체 내용·목차·표·수치·출처·미확인 검사.
