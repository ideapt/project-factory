# 이용 통계와 개선 의견

기존 GitHub Pages 앱은 그대로 사용하고, 별도 Sites 서버에 집계 이벤트와 사용자가 직접 작성한 의견만 저장합니다. 앱의 기획 제목·답변·근거·업로드 파일·원문은 전송하지 않습니다.

- 통계 참여는 선택입니다. 동의 후부터 방문 세션과 DOCX/PDF/Markdown 다운로드 요청을 집계합니다. JSON 백업은 제외합니다. 거부해도 기획 기능은 그대로 사용할 수 있습니다.
- 방문은 같은 브라우저에서 30분 이내 다시 열면 한 세션으로 봅니다. 일별 고유 브라우저는 익명 식별값을 날짜별로 해시해 구분합니다. 사람 수를 인증하는 수치는 아닙니다.
- 다운로드는 파일 생성 뒤 브라우저에 다운로드를 요청한 횟수입니다. 디스크 저장 완료·파일 열람 횟수는 알 수 없습니다.
- 수집 시작 전 사용량은 소급해 만들지 않습니다. 자동화·차단·통계 거부 때문에 전체 실제 이용량과 차이가 있을 수 있습니다.
- 통계 이벤트는 90일 범위로 조회하고 보관합니다. 의견은 운영자가 후속 검토할 수 있도록 보관합니다.
- 평점·의견은 사용자가 제출할 때만 전송합니다. 개인정보·기밀 자료를 쓰지 말라는 안내와 제출 동의를 표시합니다. 의견 본문은 운영자만 확인하고 GitHub에 자동 공개하지 않습니다.
- 운영 화면은 ChatGPT 로그인과 서버의 운영자 계정 검사로 보호합니다. 주소를 안다고 의견 내용을 읽을 수 없습니다.
- 익명 공개 수집에는 요청 크기 제한·출처 검사·일회용 제출권·속도 제한·중복 제외를 적용합니다. 봇과 조작을 완전히 막는 인증된 조사 시스템은 아닙니다.

검증할 사항: 허용하지 않은 이벤트·원본 데이터의 전송 방지, 다운로드 실패 제외, 참여 철회, 의견 동의·길이 검증, 비로그인/다른 사용자의 운영 API 차단, 저장 지속성과 실제 웹 연결.

의견 제출은 통계 참여와 별개입니다. 제출 동의 후 https://project-factory-insights.iamyangheedong.chatgpt.site 에 저장합니다. 연결 실패 시 작성 내용을 유지하며 하루 세 번까지 제출할 수 있습니다.

## 실제 이용과 시험 기록

운영 화면은 기본으로 실제 이용만 조회합니다. ‘조회 구분’을 ‘시험 기록’으로 바꾸면 시험 통계와 의견을 따로 확인할 수 있습니다. 기존 기능 점검 4건은 식별값으로 지정해 시험으로 옮겼으며 삭제하지 않았습니다.

기능 점검은 https://ideapt.github.io/project-factory/?insights=test 에서 진행하세요. 시험 표시가 나타나며 방문·다운로드·의견을 시험으로 저장합니다. 통계 동의와 세션 식별값은 일반 모드와 분리합니다. 일반 주소로 돌아가면 일반 모드입니다. 시험 모드에서도 제출 동의와 통계 동의가 필요합니다.

시험 여부는 일회용 제출권에 고정해 저장합니다. 실제 이용은 ‘시험 표시가 없는 기록’이라는 뜻으로, 운영자 방문·봇·중복 기기 등을 자동으로 모두 식별하거나 실제 사람임을 보증하지 않습니다.

## 운영자 브라우저 제외

운영 화면에서 ‘이 브라우저를 운영자용으로 지정하고 기획 도구 열기’를 누르거나 https://ideapt.github.io/project-factory/?insights=operator 로 접속하면 이 브라우저를 운영자용으로 기억합니다. 이후 일반 주소로 들어가도 동의한 방문·다운로드·제출 의견은 운영자 목록에만 포함됩니다. 일반 사용자 목록과 평점 평균에는 포함하지 않습니다. 운영자 구분 자체가 통계 참여 동의는 아니며, 동의 전 방문·다운로드를 전송하지 않습니다.

조회 구분은 ‘일반 사용자 / 운영자 / 시험 기록’입니다. 시험 주소의 기록은 운영자용 브라우저에서도 시험으로 분리합니다. 구분별 동의·익명 식별값·방문 세션은 별도로 보관합니다.

이 지정은 로그인 인증이나 운영 화면 접근 권한을 주지 않습니다. 공개 앱은 로그인 없는 GitHub Pages이므로 계정만으로 모든 기기를 자동 식별할 수 없습니다. 다른 브라우저·기기·시크릿 창에서는 각각 지정해야 하며 사이트 저장소를 지우면 재지정해야 합니다. 설정을 저장하지 못하면 안내를 표시하고 운영자 주소로 접속한 동안만 제외합니다. 설정 전 기록은 작성자를 확인할 수 없어 소급 변경하지 않습니다. 운영자로 지정한 공유 브라우저의 이용도 모두 제외되므로 개인용 브라우저에서 지정하세요.

### 화면에서 운영자 지정·해제

상단 ‘현재 집계’에서 일반 사용자·운영자·시험 여부를 확인합니다. ‘운영자 지정 해제’ 또는 ‘이 브라우저를 운영자로 지정’ 버튼으로 즉시 전환하며 새로고침할 필요가 없습니다. 운영자용 접속 주소로 들어온 뒤에도 해제와 새로고침이 정상 동작하도록 일회용 지정 주소를 일반 주소로 정리합니다. 다른 탭의 표시도 브라우저 설정 변경에 맞춰 갱신됩니다.

버튼 자체는 방문 이벤트를 보내거나 통계 동의를 변경하지 않습니다. 구분별 기존 동의·세션을 그대로 사용하고 전환 이후 발생하는 기록부터 해당 구분에 포함합니다. 이미 저장된 기록은 이동하지 않습니다. 시험 주소에서는 시험 구분이 우선하며 운영자 지정 상태도 함께 표시합니다.
