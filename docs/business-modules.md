# 사업 형태별 추가 항목

해당 유형을 하나 이상 골라 상세 기획서에 답합니다. 공통 항목을 대체하지 않습니다.

| 유형 | 추가 질문 | 초기 확인 방법 예시 |
|---|---|---|
| 제품·유통 | 최소 주문량, 재고, 불량·반품, 배송, 공급 중단에 감당 가능한가요? | 소량 견적, 샘플 검수, 포장·배송 시험 |
| 서비스·대행 | 건별 노동시간, 추가 요청, 수정 범위, 가동률은 어떤가요? | 실제 고객 과업의 유료 소규모 제공 |
| 교육 | 학습 결과, 강사 시간, 모집 비용, 환불 조건은 어떤가요? | 소수 대상 시험 운영과 학습 전후 관찰 |
| 콘텐츠·디지털 상품 | 권리, 제작비, 유통 채널, 전환율, 판매 지속기간은 어떤가요? | 일부 샘플과 가격이 명시된 제안 |
| 앱·웹·구독 | 반복 이용 이유, 해지, 지원, 서비스 운영비가 확인됐나요? | 좁은 기능의 시험 제공, 기간별 이용·유지 기록 |
| 플랫폼·중개 | 양측 고객을 확보할 수 있고 거래 성사·분쟁 처리가 가능한가요? | 한 지역·분야의 수동 중개 시험 |
| 오프라인 | 유동 인구와 실제 구매가 연결되며 임대·설비·인허가를 감당하나요? | 시간대 관찰, 단기 운영, 입점·시설 조건 확인 |

예시는 수요 검증 방법의 선택지입니다. 사업별로 필요한 권리·허가·계약 조건을 확인한 뒤 적합한 방법을 고릅니다.
