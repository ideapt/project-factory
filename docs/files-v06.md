# v0.6 · PDF·엑셀·워드 파일에서 기획 근거 가져오기

이 문서는 v0.6의 읽기 범위를 설명합니다. v0.7부터 스캔 PDF는 [OCR·원본 대조](ocr-v07.md)를 지원합니다. 아래 OCR 미지원 설명은 v0.6 당시의 제한입니다.

## 사용하는 순서

1. 기획을 선택하고 ‘PDF·엑셀·워드에서 자료 가져오기’에서 파일을 고릅니다.
2. 반영할 데이터 항목을 선택합니다. 추출 결과는 해당 항목의 단어와 일치하는 순으로 보이지만 의미가 맞다고 확정한 결과는 아닙니다.
3. 원문 단어로 검색해 필요한 발췌를 찾고 ‘선택 데이터에 반영’을 누릅니다. 같은 파일의 같은 항목을 중복 채택하지 않습니다.
4. ‘필요 데이터와 수집처’에서 반영한 내용·위치·한계를 검토합니다. 실제·추정·가상 자료의 성격과 기준 기간·범위·단위를 지정합니다. 기준 기간은 파일 수정일에서 추측하지 않습니다.
5. 실제 원문을 대조한 후 검토 확인란을 선택합니다. 이후 자료 내용을 수정하면 검토 표시가 해제됩니다. 수식·오류·생략된 항목은 검토 확인만으로 확정하지 않습니다.
6. 필요한 질문·공통 항목에 근거 번호를 연결하고 초안을 만듭니다. 초안에는 파일명·위치·해시·발췌와 추출 한계가 함께 들어갑니다.

발췌를 채택하면 데이터 항목과 초안의 자료 부분에 반영됩니다. 문서 전체를 이해해 답변을 대신 쓰거나 빠진 목표·기간·예산·판정을 만들어 넣지는 않습니다. 질문 답변과 근거의 관계는 작성자가 검토합니다.

## 지원 형식과 위치

| 형식 | 읽는 내용 | 출처 위치 |
|---|---|---|
| PDF | 텍스트로 저장된 본문 | 실제 페이지 번호와 추출행 번호 |
| XLSX·XLSM | 셀 값·저장된 수식 결과와 문맥 | 시트명·셀 주소, 병합 셀은 기준 셀 |
| DOCX | 본문 문단·본문 표 | XML 본문 문단 순서, 표·행·셀 위치 |

PDF의 추출행은 화면의 시각적 줄과 다를 수 있습니다. Word의 페이지 번호는 글꼴·편집환경에 따라 달라지므로 추정하지 않습니다. 엑셀 첫 행·첫 열은 문맥으로만 표시하며 자동으로 제목·단위를 확정하지 않습니다.

DOC·XLS는 DOCX·XLSX로 변환해 올립니다. 암호화·손상 파일은 읽기 실패로 표시합니다. 암호 입력·해제는 제공하지 않습니다. 매크로·링크·스크립트를 실행하지 않습니다.

## 미확인 처리

- PDF 페이지에 텍스트가 없으면 스캔·이미지 가능성과 OCR 미지원 상태를 표시합니다. OCR을 수행했다고 주장하지 않습니다.
- PDF의 다단 문서·표의 열 연결·그림 문자는 원문에서 대조합니다.
- 엑셀 수식은 재계산하지 않습니다. 저장된 값이 있어도 수식 결과는 불확실한 추출로 남기며, 캐시가 없으면 값은 미확인입니다.
- 엑셀 오류값, 내용 생략은 불확실한 추출로 표시합니다.
- Word의 머리글·바닥글·각주·텍스트 상자·이미지는 지원하지 않습니다. 변경 추적이 있으면 원문과 최종본을 확인하도록 표시합니다.
- 파일 추출을 반영한 자료는 처음에 ‘원문 미검토’입니다. 검토 확인과 실제 자료 지정·기간 입력을 마쳐도 ‘입력 근거 연결 — 원문·주장 적합성 미검증’으로 표시합니다. 사실 검증 완료를 자동 선언하지 않습니다.

## 파일 식별과 보관

SHA-256은 같은 이름의 다른 파일을 구분하고 원본을 다시 찾는 데 사용하는 내용 식별값입니다. 진실성·작성자 신원·법적 증명력을 보장하지 않습니다. 같은 해시의 파일은 중복 보관하지 않습니다.

원본 바이너리는 브라우저 저장이나 백업에 넣지 않습니다. 파일명·해시·추출본·발췌 위치를 저장합니다. 원본 파일은 작성자가 별도로 보관해야 합니다. 백업을 수정하면 기록도 바뀔 수 있으므로 변경 불가능한 감사 시스템은 아닙니다.

파일당 20MB·최대 5개, PDF 100페이지, 파일별 추출 1,500항목, 항목별 4,000자, 데이터 항목에 채택하는 발췌는 100개까지입니다. 제한에 도달하면 이후 내용은 미확인·생략 안내를 남깁니다. 검색 결과는 최대 50개씩 표시하며 단어로 좁혀 전체 추출본을 탐색합니다. 전체 추출본은 JSON에 포함됩니다. 압축 해제 크기도 제한합니다.

큰 파일의 추출본은 브라우저 저장 용량을 넘을 수 있습니다. 저장 실패 안내가 나오면 JSON을 내려받고 파일을 나누어 작업합니다. JSON 복원은 최대 30MB입니다. 외부 서버·AI로 파일을 전송하지 않습니다.

## 실행과 유지관리

`prototype/index.html`을 브라우저로 열어 사용합니다. 라이브러리는 `prototype/vendor`에 포함되어 있어 CDN 접속이 필요하지 않습니다. 설치 파일을 다시 준비하려면 `npm ci --ignore-scripts` 후 `node scripts/build-file-vendor.cjs`를 실행합니다.

가상 시험 자료는 [시험 자료 안내](../examples/upload-fixtures/README.md)에 있습니다. 실제 현장 데이터가 아닙니다.
