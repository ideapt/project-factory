# 공개 패키지 검증 — 2026-10-27

## 수행한 검사

1. 원래 작업 폴더에서 `npm run check` 전체 통과.
2. `python scripts/package-public.py`로 공개 ZIP·manifest 생성.
3. ZIP 경로에 상위 폴더 이동 경로가 없고, node_modules·비공개 폴더·Word 화면 캡처가 제외됐는지 검사.
4. ZIP을 별도 새 폴더 `dist/review/project-factory`에 풀고 `npm ci`로 의존성 처음 설치.
5. 새 폴더에서 `npm run check` 전체 통과. 분류·복원·초안·자료 추출·OCR·문장 보존·DOCX/PDF 생성 검사를 포함.
6. manifest에서 63개 기획 양식과 색인, GitHub Actions 파일, 100MB를 넘는 단일 파일이 없음을 확인.
7. 공개 대상 텍스트에 대표적인 API 키·GitHub 토큰·개인키 패턴이 없는지 검사. 이는 사람이 하는 전체 공개 검토를 대신하지 않음.

브라우저 실제 다운로드 검사는 [별도 기록](verification-document-export.md)에 있다. 이번에는 안내·실행 보조·패키지 구성을 바꿨으며 문서 생성 로직은 변경하지 않았다. 새 압축을 푼 폴더에서 실제 브라우저 버튼을 다시 누르는 검사는 이번 검사에 포함하지 않았다.

## 남은 항목

- 소유 계정·저장소 이름·공개 범위·자체 자료의 라이선스 결정.
- GitHub에 실제 업로드한 후 Actions 성공과 링크 확인. 현재 원격 실행은 하지 않음.
- Windows 이외 운영체제의 실제 화면 검사.
- 설치 시 기존 ExcelJS/uuid 의존성 관련 중간 수준 경고 2건이 보고됨. 이번 PDF 도구 추가와 별개의 기존 의존성이다. 무조건적인 자동 주요 버전 변경은 적용하지 않았다. 실제 배포 정책에 맞춰 별도 검토할 항목이다.

버전 표시는 기획 데이터 형식 v0.7.0을 유지한다. 배포 준비 작업이 데이터 형식 변경을 뜻하지 않는다. 공개 ZIP의 최종 크기·파일별 SHA-256은 `dist/public-manifest.json`을 기준으로 한다.
