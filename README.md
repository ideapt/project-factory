# 프로젝트 공장

## [설치 없이 웹에서 바로 사용하기 →](https://ideapt.github.io/project-factory/)

웹 화면의 **가상 호텔 예시로 시작**을 누르면 파일을 설치하거나 불러오지 않고 초안·워드·PDF 다운로드를 연습할 수 있습니다. 입력 자료는 각자의 브라우저에서 처리합니다.


직무·사업장·목적에 맞는 기획을 고르고, 자료와 출처를 연결해 기획서 초안을 만드는 한국어 도구입니다. 호텔·레지던스·FM과 회사 공통 지원업무를 포함합니다.

**현재 상태:** v0.7.0 기능 + 워드·PDF 내보내기 · 2026-10-27 공개 준비본. 로컬 컴퓨터에서 사용하는 시안이며 공인된 기획 표준은 아닙니다. 자체 코드·문서·양식은 [MIT 라이선스](LICENSE)를 적용합니다. 외부 배포물에는 각각의 라이선스가 적용됩니다.

## 처음 시작하기

1. GitHub 저장소의 **Code → Download ZIP**으로 받아 압축을 완전히 풉니다. Releases에 실행용 ZIP이 있다면 그것을 받아도 됩니다.
2. Python 3이 설치되어 있다면 Windows에서 **로컬 실행.cmd**를 두 번 누릅니다. Node.js와 API 키는 일반 사용에 필요하지 않습니다.
3. 열린 화면 하단의 **백업 불러오기**에서 `examples/material-draft-demo.json`을 선택합니다. 기존 작성 자료가 있다면 먼저 JSON으로 백업합니다.
4. **기획서 초안 만들기**를 눌러 가상 예시를 읽습니다. 내 자료로 바꾸고 **워드 내려받기 (.docx)** 또는 **PDF 내려받기 (.pdf)**를 누릅니다.

설치가 처음이라면 [설치부터 다운로드까지 따라 하기](docs/getting-started.md)를 읽으세요. 입력값과 연습 순서는 [호텔 기획 연습](examples/README.md)에 있습니다.

Python이 없다면 `prototype/index.html`을 직접 열어 작성·문서 다운로드를 사용할 수 있습니다. 스캔 PDF OCR은 웹 주소 또는 로컬 서버에서 사용합니다. 실행 주소가 바뀌면 저장본도 분리되므로 JSON으로 옮깁니다.

## 현재 기능

| 기능 | 내용 |
|---|---|
| 기획 선택 | 16개 직무·8개 사업장·8개 목적의 교차 검색, 기획 유형 63개 |
| 통합기획 | 추천 조합 9개, 여러 기획을 선택하고 공통 내용은 한 번 작성 |
| 데이터 안내 | 기획별 필요 데이터·권장 수집처·수집 방법 |
| 자료 가져오기 | PDF·XLSX·XLSM·DOCX의 텍스트·셀·문단 추출 |
| 스캔 PDF | 한국어 또는 영어 OCR, 원본 페이지와 대조, 낮은 인식 점수 표시 |
| 출처 추적 | 근거 번호·파일명·페이지/셀/문단·파일 해시·추출 원문 |
| 초안 작성 | 답변과 근거를 정리하고 부족한 부분은 ‘미확인’으로 표시 |
| 문서 다운로드 | DOCX·PDF·Markdown. Word·PDF에는 목차·표·근거 목록·페이지 번호 포함 |
| 백업 | 브라우저 저장, JSON 내보내기·복원 |

수치·출처·인용과 ‘미확인’을 임의로 보정하지 않습니다. 외부 AI, 자동 인터넷 조사, 수식 재계산, 사실 인증, 공식 승인·투자 판정은 연결되어 있지 않습니다. ‘입력 근거 연결’도 사실이 검증됐다는 뜻은 아닙니다.

## 자료와 저장

작성과 파일 처리는 브라우저 안에서 수행하며 원본을 외부 서비스로 보내지 않습니다. 현재 브라우저·접속 주소에 기획 한 건을 저장합니다. 계정·기기 동기화·팀 공동편집은 없습니다. 브라우저 기록 삭제나 저장 공간 부족에 대비해 JSON 백업을 보관하세요.

자료는 파일당 20MB, 최대 5개입니다. 일반 PDF는 최대 100페이지, OCR은 파일당 최대 10페이지를 처리합니다. DOC·XLS는 지원하지 않습니다. 인식이 불확실한 OCR이나 수식 결과는 미확인으로 남깁니다.

## 익명 이용 통계

웹 화면 하단에서 통계 참여를 선택할 수 있습니다. 동의한 방문 세션·일별 고유 브라우저와 DOCX/PDF/Markdown 다운로드 요청을 90일 범위로 집계합니다. 기획서 본문·제목·파일명·업로드 자료는 보내지 않습니다. [수집 기준과 의견 기능 상태](docs/usage-and-feedback.md)를 확인하세요. 의견 본문 전송은 목적지 승인 전까지 비활성화되어 있습니다.
