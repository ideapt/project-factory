# 파일 읽기용 가상 시험 자료

모든 값은 가상입니다. 실제 사업·현장·수요의 근거로 사용할 수 없습니다.

- [PDF](synthetic-hotel.pdf): 1페이지에 영어 가상 객실 데이터, 2페이지는 텍스트 없는 빈 페이지
- [엑셀](synthetic-hotel.xlsx): 한글 시트와 객실·정비 시간 가상값, 저장 계산값 없는 수식
- [워드](synthetic-hotel.docx): 한글 본문 문단과 표
- [스캔 PDF](synthetic-scan.pdf): 텍스트 층 없이 가상 문장을 이미지로 저장
- [스캔 원본 이미지](synthetic-scan.png): OCR 대조 시험용

생성 도구는 `python scripts/make-upload-fixtures.py`입니다. 가상 파일의 해시는 재생성 시 달라질 수 있습니다. 원문과 추출값을 대조하는 연습용입니다.
