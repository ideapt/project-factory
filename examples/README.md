# 가상 예시로 연습하기

모든 예시는 학습·시험용입니다. 실제 실적이나 업계 기준이 아닙니다.

## 객실정비 기획을 처음부터 끝까지

**백업 불러오기**에서 [가상 작성본](material-draft-demo.json)을 선택합니다. 이전 v0.5 형식이지만 현재 화면이 읽을 수 있습니다. 기존 작성 내용은 JSON으로 먼저 백업하세요.

| 항목 | 입력 내용 |
|---|---|
| 선택 기획 | 객실정비·린넨 운영 |
| 제목 | 객실정비 운영 개선 — 가상 학습 예시 |
| 대상 | 가상 A호텔 객실정비 업무 |
| 기간 | 시범 기간 미확인 |
| 배경 | 오전 퇴실 집중에 따른 객실 준비 지연이라는 가정 |
| 근거 | E-hotel-housekeeping-1 |
| 자료 성격 | 가상·연습 자료 |
| 출처 | 학습용 가상 대장 — 실제 외부 원자료 없음 |
| 내용 | 퇴실 객실 20개가 오전에 집중되는 가상 상황 |
| 미확인 | 실제 정비·검수시간, 비용·인력, 기준선과 목표 |

1. **기획서 초안 만들기**를 누릅니다.
2. 가상 자료가 ‘미확인 — 가상·연습 자료’로 남는지 확인합니다.
3. 예산 칸에 `가상 연습: 1,000,000원 / 실제 예산 미확인`을 입력합니다.
4. 워드·PDF를 받아 같은 수치와 미확인이 있는지 확인합니다.
5. JSON 백업을 받아 다시 불러온 뒤 예산이 복원되는지 확인합니다.

[생성 예시 전문](material-draft-demo.md)도 함께 읽어 보세요.

## 파일 읽기·OCR

[가상 시험 파일 안내](upload-fixtures/README.md)의 PDF·엑셀·워드·스캔 PDF를 사용합니다. 파일을 읽은 것만으로 초안에 반영되지는 않습니다. 데이터 항목을 고르고 블록을 반영한 뒤 근거 번호를 연결합니다.
